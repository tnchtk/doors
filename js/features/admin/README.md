# Административная панель

Экран администрирования справочников, резервных копий и локального хранилища.

## Архитектурные границы

- Общие элементы интерфейса и навигация остаются в `js/core/`.
- Функции раздела размещаются в `js/features/admin/admin.js`.
- Без настроек Supabase приложение использует IndexedDB в браузере, с переносом старых данных из localStorage и резервным fallback на localStorage.
- При заполненном `js/core/cloud-config.js` приложение требует вход в Supabase и использует общую запись `public.app_state`.
- Резервные копии экспортируются и импортируются в формате JSON.

Локальный выбор роли демонстрационный. Для совместной работы используется Supabase Auth и политика доступа к общей записи состояния. Одновременные сохранения проверяют номер версии; при конфликте экран перечитывает общую базу и просит повторить правку.
