# СметаДверь — учёт монтажа дверей

Веб-приложение для учёта объектов, дверей, монтажных бригад, закупок и материалов на складе. Проект рассчитан на работу небольшой команды до 10 сотрудников.

## Запуск

Это статический сайт: сборка и установка npm-пакетов не нужны. Главная страница проекта — `index.html`; папки `assets/` и `js/` должны находиться рядом с ним в корне проекта.

Для публикации подключите GitHub-репозиторий к Vercel. Выберите статический проект (Other): команда сборки не требуется, корневая папка — корень репозитория.

Опубликованный сайт: [doors-kappa.vercel.app](https://doors-kappa.vercel.app/)

## Общая база Supabase

В `js/core/cloud-config.js` уже указаны адрес проекта Supabase и Publishable key. Этот ключ предназначен для браузерного приложения. Не добавляйте в файлы сайта пароль базы данных, Secret key или service-role key.

Перед первым использованием общей базы:

1. В Supabase откройте **SQL Editor** и выполните содержимое файла [`js/data/data-base.sql`](js/data/data-base.sql) один раз.
2. Там же выполните [`js/data/data-base-roles.sql`](js/data/data-base-roles.sql), чтобы включить роли администратора, менеджера и бригадира.
3. Выполните [`js/data/data-base-object-management.sql`](js/data/data-base-object-management.sql), чтобы только администратор мог окончательно удалять объекты и блоки.
4. В Supabase откройте **Authentication → Users** и создайте или пригласите сотрудников. Вход в сайт выполняется по электронной почте и паролю; формы самостоятельной регистрации в приложении нет.
5. Разрешите адрес сайта в **Authentication → URL Configuration**. Для текущей публикации адрес уже настроен: `https://doors-kappa.vercel.app/`. Если Vercel выдаст другой домен, добавьте новый адрес туда же.
6. Откройте сайт и войдите под учётной записью сотрудника. Новая общая база изначально пустая.

SQL-схема создаёт общую запись данных, профили пользователей, правила доступа и сохранение с проверкой версии. Ограничение базы — не более 10 активных профилей сотрудников. Профиль автоматически создаётся для новых пользователей Supabase Auth. Если учётную запись создали до выполнения SQL-файла, для неё может понадобиться отдельный профиль.


## Локальный режим и резервные копии

Когда `enabled` в `js/core/cloud-config.js` установлен в `false`, данные хранятся только в браузере и не синхронизируются между устройствами. Включённая общая база требует входа сотрудника.

В разделе **Администрирование** можно скачать резервную копию данных в формате JSON или восстановить данные из такой копии.

## Файлы проекта

- `index.html` — страница приложения и подключение скриптов.
- `assets/css/` — стили интерфейса.
- `js/core/` — хранение данных, настройки Supabase, навигация и экспорт.
- `js/data/` — SQL-схема общей базы и начальные данные.
- `js/features/` — экраны объектов, бригад, закупок, склада, проблем и отчётов.
- `js/main.js` — запуск приложения.
